# EdItOr Studio

EdItOr — визуальная среда для создания приложений под компьютеры, телефоны, планшеты и веб.

## Технологии

- **Tauri 2 + Rust** — desktop shell и системный backend.
- **Svelte 5 + TypeScript** — интерфейс редактора.
- **Vite** — локальная разработка и production-сборка.

## Сейчас реализовано

- Стартовый экран создания проекта.
- Выбор целевой платформы: компьютер, телефон, планшет или веб.
- Название проекта и краткое подтверждение выбранных параметров.
- Адаптивная раскладка для узких экранов.

## Запуск

Требуются Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Проверка и production-сборка:

```bash
npm run build
```

## Tauri

Для запуска desktop-оболочки установите системные зависимости Tauri 2 для своей ОС, затем выполните:

```bash
npm run tauri dev
```

## План

1. Настройки проекта и сохранение проекта.
2. Рабочая область с блочным редактором.
3. Библиотека компонентов и тем оформления.
4. Предпросмотр и экспорт под выбранную платформу.

Пока это ранний каркас: выбор платформы работает в интерфейсе, а полноценный редактор и экспорт ещё не реализованы.
