# EdItOr Studio

Визуальная среда разработки приложений для компьютеров, телефонов, планшетов и веба.

## Технологии

- **Tauri 2 + Rust** — desktop shell и системный backend.
- **Svelte 5 + TypeScript** — интерфейс.
- **Blockly** — визуальное программирование и генерация JavaScript.
- **Vite** — разработка и production-сборка.

## Уже реализовано

- Стартовый экран с выбором целевой платформы.
- Название проекта и переход в рабочее пространство.
- Блочный редактор на Blockly: логика, циклы, математика, текст, переменные, функции и блоки интерфейса.
- Автоматическая генерация JavaScript из блоков.
- Локальное сохранение рабочей области Blockly в браузерном хранилище.
- Панель сгенерированного кода и копирование кода.
- Каталог дизайн-систем: Material 3, Fluent 2, iOS 26 и Carbon.
- Анимации интерфейса с поддержкой prefers-reduced-motion.
- Адаптивная компоновка.

## Запуск

Требуются Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Проверка и production-сборка:

```bash
npm run build
```

## Tauri

Установите системные зависимости Tauri 2 для своей ОС, затем:

```bash
npm run tauri dev
```

## Что пока не готово

- Генерация готовых APK/EXE/установщиков.
- Полный runtime для запуска созданного интерфейса.
- Применение всех дизайн-токенов библиотек непосредственно к генерируемому приложению.
- Сохранение и управление несколькими проектами.

Библиотеки в текущей версии представлены каталогом дизайн-систем; интеграция их официальных компонентов и токенов будет отдельным этапом.
