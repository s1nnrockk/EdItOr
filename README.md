# EdItOr Studio

Визуальная среда разработки приложений для компьютеров, телефонов, планшетов и веба.

## Технологии
- Tauri 2 + Rust — desktop shell.
- Svelte 5 + TypeScript — интерфейс.
- Blockly — визуальное программирование.
- CodeMirror 6 — редактор исходного кода с подсветкой синтаксиса.
- Vite — разработка и production-сборка.

## Реализовано
- Стартовый экран выбора целевой платформы.
- Визуальный блочный редактор с Blockly.
- Переключение между блочным режимом и обычным редактированием JavaScript.
- Автоматическая генерация JavaScript из блоков.
- Локальное сохранение рабочего пространства Blockly.
- Внутренний файловый обозреватель проекта: создание, редактирование и удаление файлов.
- История локальных коммитов со снимками файлов и восстановлением версии.
- Импорт и экспорт локального проекта в JSON.
- Каталог из 20 дизайн-систем и UI-библиотек с назначением и ссылками на официальную документацию.
- Адаптивная компоновка и ненавязчивые переходы с поддержкой prefers-reduced-motion.

## Запуск
Требуются Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Проверка и production-сборка:

```bash
npm run build
```

Для запуска desktop-оболочки установите системные зависимости Tauri 2:

```bash
npm run tauri dev
```

## Важные ограничения текущей версии
- Встроенный репозиторий пока локальный: он хранит файлы и историю в хранилище приложения, но не подключается к GitHub и не выполняет git push/pull.
- Каталог дизайн-систем содержит реальные названия, описание и официальные ссылки. Автоматическая установка пакетов и применение всех официальных компонентов/токенов к проекту ещё не реализованы.
- Режим обычного кода сейчас предоставляет отдельный JavaScript-редактор; полноценный многофайловый runtime и синхронизация кода с блочной схемой ещё впереди.
- Экспорт готовых APK/EXE/установщиков будет отдельным этапом.
